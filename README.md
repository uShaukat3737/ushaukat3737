# 🚀 Projects:

**Tech Stack:** GitHub Actions, Node.js, Vercel, Snyk, Docsify
- Forked an open-source satellite tracking app and engineered a complete 7-workflow GitHub Actions CI/CD pipeline from scratch.
- Built a CI workflow triggered on every push and PR to main: automated ESLint linting, npm test execution, npm audit security scanning, and artifact upload.
- Automated production deployment to Vercel via a secrets-managed deploy workflow.
- Implemented a PR code review workflow running ESLint static analysis and Snyk vulnerability scanning.
- Integrated Dependabot PR validation and configured automated documentation deployment to GitHub Pages using docsify.
- Added automated release notes generation using GitHub Script and a weekly scheduled maintenance cron job.

- Implemented automated testing suites (unit, integration, E2E) using Jest and Cypress to ensure application reliability and regression safety.
- Integrated real-time error monitoring and performance tracking using Sentry for production observability.
- Automated build, test, and deployment workflows using Jenkins, enabling consistent and repeatable releases.

### Vidly — Movie Rental Backend API
**Tech Stack:** Node.js, Express, MongoDB, JWT
- Built a production-ready RESTful API supporting 6 core domains with full CRUD operations.
- Implemented JWT-based authentication and role-based authorization (RBAC) with secure password hashing using bcrypt.
- Designed a rental workflow system with real-time stock management, embedded documents, and automated late-fee calculation.
- Developed a centralized async error-handling middleware to eliminate repetitive try/catch logic.
- Secured application using Helmet, Joi validation, and ObjectId sanitization.
- Wrote comprehensive test suites (Jest + Supertest) and deployed on Render with MongoDB Atlas.

### Dockerized Vault System — Backend & Deployment
**Tech Stack:** Node.js, MongoDB, Docker, Docker Compose
- Containerized a Node.js backend and MongoDB database using Docker and Docker Compose to ensure consistent cross-environment deployment.
- Designed and implemented core backend features including search, sorting, automated backups, and vault analytics.

### CareerConnect — Job Fair Management System
**Tech Stack:** C#, SQL Server, Windows Forms, ADO.NET
- Designed and normalized a relational database (3NF) to manage students, companies, and application workflows.
- Implemented stored procedures for secure authentication and efficient data retrieval.
- Built a role-based access control (RBAC) system supporting multiple user types.
- Developed a desktop-based management interface using Windows Forms with ADO.NET for seamless database interaction.

### RestaurantHub — Management System & Delivery Engine
**Tech Stack:** C++, Data Structures & Algorithms
- Engineered a complete system using custom data structures (Linked Lists, Binary Search Trees, Heaps) with manual memory management, avoiding STL usage.
- Built a priority queue-based order processing engine to efficiently schedule and manage incoming orders.
- Implemented shortest-path optimization (Dijkstra’s algorithm) on a weighted graph to compute optimal delivery routes.
- Designed a hash-based authentication system with custom collision handling for O(1) user lookup.

### Efficient Computer Vision Inference System — Async ML Backend & Performance Optimization
**Tech Stack:** FastAPI, Redis, multiprocessing
- Built a production-grade async ML inference backend using FastAPI, Redis, and multiprocessing, achieving 277 RPS via queue-based batch scheduling; implemented deployment with Docker Compose.
- Implemented a dual-threshold batch scheduler (batch size = 8 / 20ms timeout) with per-request latency metrics exposed via a /metrics endpoint.
- Identified and corrected a threading imbalance in ONNX vs PyTorch benchmarking, reducing an inflated 8× speedup to a validated 2.5×.
